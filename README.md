# Capstone Project IBM Bob: CV Information Extractor

## 📌 Ringkasan Project
Project ini mengembangkan AI Agent berbasis IBM Bob untuk mengekstrak informasi penting dari CV pelamar secara otomatis guna mempercepat proses screening HRD.

## 👥 Target Users
- Tim Rekruter & HR Specialist perusahaan.

## 🛠️ Arsitektur Prompt (Prompt Layering)
1. **System Persona:** Mengatur AI sebagai HR Assistant yang profesional.
2. **Context & Input:** Menerima input teks CV mentah dari pengguna.
3. **Task & Output:** Mengubah data mentah menjadi format terstruktur (Nama, Kontak, Pengalaman, Skills, Pendidikan, Rekomendasi).

## 🚀 Cara Penggunaan di IBM Bob
1. Masukkan prompt system dan instruksi tugas ke IBM Bob.
2. Masukkan teks CV pada kolom input/playground.
3. AI akan mengembalikan ringkasan data kandidat secara instan.
